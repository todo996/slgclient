# Game assets

Thư mục đích dành cho tài nguyên được tái sử dụng từ `assets/resources`.

Trong mốc nền tảng chưa sao chép asset dung lượng lớn. Khi port map, giữ nguyên tên
và cấu trúc thư mục càng gần bản Cocos càng tốt; không sao chép file `.meta`,
`.scene`, `.prefab` hoặc `.anim` vào runtime web.
